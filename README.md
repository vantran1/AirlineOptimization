# AirlineOptimization
Welceom to Van and Marcos' Final Project for 6.7200/15.093!

In the data folder, you will find helpful data for the project. The payload and range .csv files have headers of aircraft (by IATA code) and integer values. The payload file gives you the maximum seating capacity for each aircraft. The range gives tells you the maximum range at full payload. The coordinates file gives you the coordinates of major airports around the United States.
